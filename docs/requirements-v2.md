## 2. ข้อมูลที่เพิ่ม

| ฟิลด์ | ที่มา | ใช้ทำอะไร |
|---|---|---|
| `prev` | ราคาปิดของแท่งก่อนแท่งล่าสุด (`close.iloc[-2]`) ใน `scripts/build_data.py` | คำนวณการเปลี่ยนแปลงของ US10Y เป็น bp |

- การเปลี่ยนแปลงรายวัน `chg1d = ราคาปิดล่าสุด / ราคาปิดวันก่อนหน้า − 1` (สูตรเดิมของ v1)
- **US10Y** แสดงเป็นการเปลี่ยนแปลงของ yield ในหน่วย **bp** = `(yield ล่าสุด − yield วันก่อนหน้า) × 100` ไม่ใช้ %
- ถ้าไฟล์ข้อมูลรอบเก่ายังไม่มี `prev` หน้าเว็บจะคำนวณย้อนกลับจาก `last / (1 + chg1d)` แทน
- "วันก่อนหน้า" คือวันทำการก่อนหน้าของ**ตลาดนั้นเอง** ตลาดสหรัฐฯ จึงมักเป็นข้อมูลของวันก่อนตลาดเอเชีย 1 วันเพราะต่างเวลา

## 3. Features ใหม่ (หน้า Dashboard `index.html`)

### 3.1 Masthead
- พื้นไล่เฉดสีน้ำเงินเข้ม (`#0f2740` → `#24496b`) ตัวอักษรสีครีม **ใช้สีเดียวกันทั้งโหมดสว่างและโหมดมืด**
- บรรทัดตัวเล็ก "GLOBAL MARKETS · TECHNICAL DESK" + ชื่อ dashboard ตัวใหญ่
- ฝั่งขวา: จุดสีทองกะพริบ, วันที่ข้อมูล, เวลาอัปเดตล่าสุด และรอบอัปเดตอัตโนมัติ 04:47 / 18:13 น.
- ไม่มีชื่อหรือโลโก้องค์กร (เหมือน v1)

### 3.2 Ticker ribbon
- อยู่ใต้ masthead พื้นสีน้ำเงินเกือบดำ (`#0b1826`)
- แต่ละช่อง: **ชื่อ · ระดับล่าสุด · ▲/▼ การเปลี่ยนแปลงรายวัน** สีเขียว = ขึ้น, สีแดง = ลง
- ครบทั้ง 19 สินทรัพย์ เรียงตามลำดับใน `config.py` US10Y แสดงระดับเป็น % และการเปลี่ยนแปลงเป็น bp
- เลื่อนจากขวาไปซ้ายวนต่อเนื่อง (ประมาณ 70 วินาทีต่อรอบ) **หยุดเมื่อเอาเมาส์ชี้**
- คลิกแต่ละช่องเพื่อเปิดหน้ากราฟของสินทรัพย์นั้น
- ผู้ใช้ที่ตั้งค่า "ลดการเคลื่อนไหว" (prefers-reduced-motion) จะได้แถบนิ่งที่เลื่อนด้วยมือแทน

### 3.3 Daily Change Map
การ์ดแรกของหน้า อยู่เหนือ Performance

**แผนที่**
- แผนที่โลก projection Natural Earth ตัดช่วงละติจูดประมาณ −28° ถึง 60° ไม่แสดงแอนตาร์กติกา
- ประเทศที่มีดัชนีใน dashboard แรเงาเข้มกว่า (STOXX 600 แรเงาประเทศหลักในยุโรป)
- ข้อมูลขอบเขตประเทศ: `world-atlas@2.0.2/countries-110m.json` วาดด้วย `d3@7.9.0` + `topojson-client@3.1.0` (โหลดจาก jsDelivr)

**Bubble**
- แสดง**ดัชนีหุ้น 15 ตัว** หนึ่ง bubble ต่อหนึ่งดัชนี
- **พื้นที่** bubble แปรผันตาม |% เปลี่ยนแปลงรายวัน| (scale แบบ square root) รัศมี 4–32 px โดยตัวที่เปลี่ยนมากที่สุดของวันได้ขนาดใหญ่สุด ถ้าทุกตัวเปลี่ยนน้อยกว่า 1% จะใช้ 1% เป็นเพดานของ scale
- สี: เขียว = ขึ้น, แดง = ลง, เทา = ไม่เปลี่ยน
- ใต้ bubble มีชื่อย่อและ % เปลี่ยนแปลง
- ตลาดที่มีหลายดัชนี (สหรัฐฯ 4, ฮ่องกง 3, จีน 2, ญี่ปุ่น 2) ใช้ force simulation ดัน bubble ไม่ให้ทับกัน และมี**เส้นโยง**กลับไปจุดที่ตั้งตลาด
- ชี้เมาส์: ชื่อเต็ม, ระดับล่าสุด, % เปลี่ยนแปลง และวันที่ข้อมูล · คลิก: เปิดหน้ากราฟ

**ตำแหน่ง bubble**

| ดัชนี | ตำแหน่ง | ดัชนี | ตำแหน่ง |
|---|---|---|---|
| S&P 500, Nasdaq, Nasdaq 100, Russell 2000 | สหรัฐฯ | HSI, HS Tech, HSCEI | ฮ่องกง |
| STOXX 600 | ยุโรปกลาง | Sensex | อินเดีย |
| Nikkei 225, TOPIX | ญี่ปุ่น | KOSPI | เกาหลีใต้ |
| CSI 300 | จีน | SET | ไทย |
| SSE | เซี่ยงไฮ้ | | |

**คำอธิบายเหนือแผนที่:** สีขึ้น/ลง, วงอ้างอิงขนาด 0.5% / 1% / 2% (ขนาดเท่ากับ bubble บนจอจริง) และหมายเหตุว่าตลาดสหรัฐฯ อาจเป็นข้อมูลของวันทำการก่อนหน้า

**การ์ด cross-asset ใต้แผนที่:** US 10Y Yield, Gold Spot, Brent Oil, USD/THB ไม่มีประเทศเดียวให้ปักบนแผนที่ จึงแสดงเป็นการ์ด 4 ใบ (บนมือถือเป็น 2×2) แต่ละใบมีระดับล่าสุดและการเปลี่ยนแปลง คลิกเพื่อเปิดกราฟ

**ข้อจำกัด**
- ถ้าโหลด d3 หรือข้อมูลแผนที่จาก CDN ไม่ได้ จะขึ้นข้อความ "โหลดแผนที่ไม่สำเร็จ" ส่วนอื่นของหน้าใช้งานได้ตามปกติ
- บนมือถือแผนที่กว้างขั้นต่ำ 760 px ต้องเลื่อนซ้ายขวา เพื่อให้ตัวหนังสือยังอ่านออก

### 3.4 Strategy glossary แบบหุบได้
- **หุบเป็นค่าเริ่มต้น** เห็นแค่แถบ "▸ คำอธิบาย Strategy (Glossary)" และคำว่า "แสดงคำอธิบาย" ทางขวา
- คลิกแถบเพื่อคลี่หรือหุบ ลูกศรหมุนลง และคำทางขวาเปลี่ยนเป็น "ซ่อน"

- เนื้อหาข้างในเหมือน v1 ทุกอย่าง

## 5. รอบอัปเดตและการแสดงข้อมูลล่าสุด (แก้ 17 พ.ย. 2026)

**ปัญหาที่พบ:** รอบ 05:30 ของวันที่ 17 พ.ย. เริ่มช้าไปประมาณ 6 ชั่วโมง เพราะ GitHub เลื่อนหรือข้ามรอบตามเวลาในช่วงที่ระบบมีงานเยอะ โดยเฉพาะนาที :00 และ :30 ส่วนตัวงานเองใช้เวลาไม่ถึง 1 นาที

| รอบ | เวลา (ไทย) | cron (UTC) | วัน | เหตุผล |
|---|---|---|---|---|
| หลังตลาดสหรัฐฯ ปิด | **04:47** | `47 21 * * 0-5` | จันทร์–เสาร์ | ตลาดสหรัฐฯ ปิด 03:00–04:00 น. ตามช่วง DST |
| สำรองรอบเช้า | **06:13** | `13 23 * * 0-5` | จันทร์–เสาร์ | ยังทันก่อนญี่ปุ่นและเกาหลีเปิด 07:00 น. |
| หลังตลาดเอเชียปิด | **18:13** | `13 11 * * 1-5` | จันทร์–ศุกร์ | อินเดียปิด 17:00 น. |
| สำรองรอบเย็น | **19:07** | `7 12 * * 1-5` | จันทร์–ศุกร์ | |

- ใช้นาทีที่ไม่ลงตัว เพื่อหลบช่วงคิวแน่น
- รอบสำรองจะดึงข้อมูลซ้ำและ commit อีกครั้ง ราคาเหมือนเดิม แต่ "อัปเดตเมื่อ" จะเป็นเวลาของรอบสำรอง ไม่มีผลเสีย
- STOXX 600 ปิด 23:30 น. จึงได้ข้อมูลวันนั้นในรอบเช้าถัดไป
- หน้าเว็บขอ `data/*.json` พร้อม `?t=<เวลา>` เพื่อข้าม cache 10 นาทีของ GitHub Pages ส่วนไฟล์ HTML/CSS/JS ยังติด cache ได้ถึง 10 นาทีหลังแก้หน้าตา
- ถ้าต้องการให้ตรงเวลาแน่นอน ทางเลือกต่อไปคือใช้บริการ cron ภายนอกสั่งรันผ่าน workflow_dispatch

### 6.2 Market Pulse
| ช่อง | ค่า |
|---|---|
| ตลาดหุ้นวันนี้ | จำนวนดัชนีหุ้นที่ขึ้น / ลง (จาก 15) + แถบสัดส่วน |
| เฉลี่ย 15 ดัชนี | ค่าเฉลี่ย % เปลี่ยนแปลงรายวัน ถ่วงน้ำหนักเท่ากัน |
| แนวโน้ม | จำนวน UPTREND / SIDEWAYS / DOWNTREND ของ 19 สินทรัพย์ |
| RRG | จำนวนดัชนีในแต่ละ quadrant |
| Strategy | BREAKOUT + BUY DIP และจำนวนของแต่ละ Strategy |

### 6.3 Top Movers และ Cross-Asset
- **Top Movers:** อันดับ % เปลี่ยนแปลงรายวันของดัชนีหุ้นครบ 15 ตัว พร้อมแถบความยาวตามขนาด (ปรับในหัวข้อ 7.3)
- **Cross-Asset:** ย้ายจากใต้แผนที่มาอยู่ข้างแผนที่ แสดงเป็นรายการ (US 10Y เป็น bp)
- แผนที่ครอปละติจูด −16° ถึง 60° ถ้าจอแคบ แผนที่จะเลื่อนซ้ายขวาได้ และเริ่มที่ฝั่งเอเชีย

### 6.4 ตารางสรุป
- **ปุ่มกรอง:** ทั้งหมด / สหรัฐฯ / ยุโรป / เอเชีย / สินทรัพย์อื่น
- **คลิกหัวคอลัมน์:** เรียงมากไปน้อย → คลิกซ้ำเพื่อเรียงน้อยไปมาก → คลิกครั้งที่สามเพื่อกลับไปแบบจัดกลุ่มตามตลาด
- **คอลัมน์ข้อความ:** เช่นชื่อ เรียง ก→ฮ / A→Z ก่อน
- **คอลัมน์แนวโน้ม / Strategy / Quadrant:** เรียงตามลำดับความแข็งแรง เช่น BREAKOUT > BUY DIP > WATCH > CORRECTION > AVOID
- **คอลัมน์ "3 เดือน":** sparkline ราคาปิด 63 วันทำการล่าสุด สีเขียวหรือแดงตามผลตอบแทนช่วงนั้น พร้อม % เปลี่ยนแปลง
- **ข้อมูลใหม่:** `summary.json` มีฟิลด์ `spark` (ราคาปิด 63 ค่าล่าสุด) ถ้ายังไม่มี หน้าเว็บจะอ่านจาก `data/assets/<ID>.json` แทน

### 6.5 การ์ดแท็บ
- Performance, Market Rotation และ RRG รวมเป็นการ์ดเดียว สลับด้วยแท็บ ใช้ปุ่มลูกศรซ้ายขวาบนคีย์บอร์ดได้
- จำแท็บล่าสุดไว้ในเบราว์เซอร์ของผู้ชม
- ลิงก์ `#performance`, `#rotation`, `#rrg` จะเปิดแท็บนั้นให้

## 7. Risk-On / Risk-Off Gauge และสินทรัพย์ใหม่ (17 พ.ย. 2026)

### 7.1 สินทรัพย์ที่เพิ่ม (19 → 22 ตัว)

| ตลาด | สินทรัพย์ | TradingView symbol | หมายเหตุ |
|---|---|---|---|
| พันธบัตรสหรัฐฯ | US 2-Year Yield | `TVC:US02Y` | แสดงเป็น % และเปลี่ยนแปลงเป็น bp เหมือน US10Y · ไม่อยู่ใน Performance/Rotation |
| อัตราแลกเปลี่ยน | US Dollar Index | `TVC:DXY` | อยู่ใน Performance/Rotation |
| ความผันผวน | VIX | `TVC:VIX` | **ไม่มี Strategy** (ดัชนีความกลัว ถ้าใช้กฎเดียวกัน "BREAKOUT" จะอ่านผิดความหมาย) · ไม่อยู่ใน Performance/Rotation |

**ใช้คำนวณ gauge อย่างเดียว ไม่แสดงเป็นแถว:**
- `AMEX:HYG` (หุ้นกู้ high yield)
- `NASDAQ:IEF` (พันธบัตรรัฐบาลสหรัฐฯ 7–10 ปี)
- `COMEX:HG1!` (ทองแดง สัญญาต่อเนื่อง)

ไฟล์ของสินทรัพย์เหล่านี้ยังเก็บไว้ใน `site/data/assets/` เพื่อให้ใช้ข้อมูลรอบก่อนได้ถ้าดึงไม่สำเร็จ

**ข้อมูลใหม่ใน `summary.json`:**
- `unit` ("yield" / "level") บอกรูปแบบการแสดงผล
- `normalize()` ตัดแท่งที่ตกวันเสาร์-อาทิตย์ทิ้ง เผื่อกรณีสัญญาซื้อขายล่วงหน้าหรือ FX ที่มี session วันอาทิตย์

### 7.2 สูตร Gauge

| สัญญาณ | ค่าดิบ | ทิศทาง |
|---|---|---|
| Breadth หุ้นโลก | % ของดัชนีหุ้น 15 ตัวที่ราคาปิด > EMA50 | สูง = Risk-On |
| หุ้นโลก / ทองคำ | ACWI ÷ ทองคำ เปลี่ยนแปลง 20 วัน | สูง = Risk-On |
| Credit | HYG ÷ IEF เปลี่ยนแปลง 20 วัน | สูง = Risk-On |
| ทองแดง / ทองคำ | HG1! ÷ ทองคำ เปลี่ยนแปลง 20 วัน | สูง = Risk-On |
| VIX | ระดับ VIX | สูง = Risk-Off (กลับด้าน) |
| ดอลลาร์ | DXY เปลี่ยนแปลง 20 วัน | สูง = Risk-Off (กลับด้าน) |

1. ทุก series จัดลงปฏิทินวันทำการของ ACWI (ตลาดสหรัฐฯ) แล้ว forward-fill ไม่เกิน 5 วัน อัตราส่วนจึงเทียบวันเดียวกันเสมอ
2. แต่ละสัญญาณแปลงเป็น **percentile แบบ rolling 252 วัน** (ต้องมีข้อมูลอย่างน้อย 126 วัน) × 100 สัญญาณที่กลับด้านใช้ 100 − percentile ไม่ใช้ข้อมูลในอนาคต
3. **คะแนน** = ค่าเฉลี่ยของสัญญาณที่มีค่า (ต้องมีอย่างน้อย 4 จาก 6)
4. ช่วงคะแนน: ≥ 70 Risk-On · 55–70 เอียง Risk-On · 45–55 Neutral · 30–45 เอียง Risk-Off · ≤ 30 Risk-Off
5. แสดงการเปลี่ยนแปลงเทียบ 5 วันทำการก่อน และประวัติ 252 วันทำการล่าสุด
6. **Yield curve 2s10s** = (US10Y − US02Y) × 100 bp แสดงประกอบเท่านั้น ไม่นับในคะแนน

**ผลลัพธ์ใน `summary.json` → `risk`:**
- `date`, `score`, `label`, `chg5d`
- `components[]`: `key`, `name`, `desc`, `sign`, `raw`, `pct`
- `history[]`: `d`, `s`
- `curve`: `bp`, `chg20d`

### 7.3 การแสดงผล
**แถว Macro:** อยู่ใต้ Market Pulse แบ่งเป็นสองการ์ด ฝั่งละครึ่งหน้า (จอแคบกว่า 1100 px จะเรียงลงมา)

**ฝั่งซ้าย: Risk-On / Risk-Off Gauge**
- **หน้าปัดขนาดเล็ก:** คะแนน 0–100, ป้ายภาวะตลาด และการเปลี่ยนแปลงจากสัปดาห์ก่อน
- **แต่ละสัญญาณบรรทัดเดียว:** ชื่อ · แถบบางเริ่มจากกึ่งกลาง (50) ไปทาง Risk-On (เขียว) หรือ Risk-Off (แดง) · ค่าดิบ ชี้เมาส์เพื่อดูความหมายและ percentile
- **กราฟย้อนหลัง 1 ปีแบบเตี้ย:** มีแถบสีตามช่วงคะแนน ชี้เมาส์เพื่อดูค่ารายวัน ด้านล่างแสดง 2s10s
- **หัวข้อ "วิธีคำนวณ":** คลี่อ่านได้ในการ์ด
- ถ้า `summary.json` ยังไม่มี `risk` การ์ดจะซ่อนไว้

**ฝั่งขวา: Cross-Asset**
- ย้ายมาจากคอลัมน์ข้างแผนที่
- มี 7 ตัว: US10Y, US2Y, ทอง, Brent, USD/THB, DXY, VIX
- แต่ละแถวมีกราฟเส้น 3 เดือนพร้อม % (บนมือถือซ่อนกราฟเส้น), ระดับล่าสุด และการเปลี่ยนแปลงรายวัน

**คอลัมน์ข้างแผนที่:** เหลือ Top Movers อย่างเดียว แสดงอันดับครบ 15 ดัชนี มีเส้นประ "0%" คั่นระหว่างตัวที่บวกกับตัวที่ลบ การ์ดยืดสูงเท่าการ์ดแผนที่เสมอ แถวกระจายเต็มความสูงการ์ด

## 9. หน้ากราฟเทคนิคและ Chart Pack PDF (18 พ.ย. 2026)

**หน้ากราฟ (`chart.html`)**
- **กล่องคำอธิบาย:** เอาแถว Strategy ออก
- **Divergence:** เอาเส้น divergence ออกจากกราฟและจาก legend
  - ช่อง checkbox เปลี่ยนชื่อจาก "RSI + Divergence" เป็น "RSI"
  - ถ้าเพิ่งเกิด divergence ภายใน 15 แท่งล่าสุด ยังบอกเป็นข้อความในแถว RSI และในย่อหน้า "แนวโน้ม"
- **ป้ายแนวรับ/แนวต้าน:** ป้ายชื่อ (S1, R1, …) วาดไว้ชิดซ้ายสุดของกราฟ ไม่บังแท่งเทียนล่าสุด
  - แกนราคาด้านขวายังมีป้ายตัวเลขราคาของแต่ละเส้น
  - ป้ายที่อยู่ใกล้กันจะถูกดันแยก ไม่ให้ซ้อนกัน
  - ป้ายวาดลงบน canvas จึงติดไปกับภาพ PDF ด้วย
- **Export PDF:** แก้ปัญหากดครั้งแรกแล้วภาพกราฟไม่ขึ้น
  - ภาพสำหรับพิมพ์ถูกเตรียมล่วงหน้าทุกครั้งที่กราฟเปลี่ยน
  - ปุ่มจะรอให้ภาพโหลดเสร็จก่อนเปิดหน้าต่างพิมพ์
- **โค้ดกราฟ:** ย้ายไปไว้ใน `assets/techchart.js` ใช้ร่วมกันระหว่าง `chart.html` และ `pack.html`

**Chart Pack (`pack.html`)**
- **การเปิด:** ปุ่ม "⤓ Chart Pack (PDF)" ทางขวาของแถบเมนู เปิดในแท็บใหม่
  - หน้า pack สร้างกราฟทุกตัวและแสดงตัวอย่างทุกหน้า ไม่เปิดหน้าต่างพิมพ์เอง
  - ผู้ใช้กดปุ่ม "บันทึกเป็น PDF" (เปิดใช้ได้เมื่อสร้างครบ) แล้วเลือก Save as PDF
- **รูปแบบ:** A4 แนวนอน หน้าละหนึ่งสินทรัพย์
- **หน้าปก:** ตามแบบ cover
  - พื้นน้ำเงินเข้ม หัวข้อ "Technical Charts"
  - บรรทัดรองสีเหลือง "กราฟแท่งเทียน + EMA50/200 + RSI + แนวรับ-แนวต้าน"
  - จำนวนสินทรัพย์และวันที่ข้อมูล
- **ลำดับ:** หุ้น → พันธบัตร → ค่าเงิน → สินค้าโภคภัณฑ์ → ความผันผวน
  - หุ้นเรียงตามประเทศเหมือนตารางสรุป: สหรัฐฯ, ยุโรป, ญี่ปุ่น, จีน, ฮ่องกง, อินเดีย, เกาหลีใต้, ไทย
- **แต่ละหน้า:** กราฟช่วง 1Y พร้อม EMA50/200, RSI และแนวรับ/แนวต้าน
  - มีกล่องคำอธิบายแบบเดียวกับหน้ากราฟ
- **ท้ายหน้า:** ทุกหน้ามีคำว่า "Internal Use Only" ตรงกลางด้านล่าง และเลขหน้าทางขวา
- **ชื่อไฟล์เริ่มต้น:** `Technical Chart Pack - <วันที่ข้อมูล>`

**ตาราง Cross-Asset:** เพิ่มหัวคอลัมน์ สินทรัพย์ · 3 เดือน · ระดับล่าสุด · เทียบวันก่อน
- จอเล็กจะซ่อนคอลัมน์ 3 เดือนพร้อมกราฟเส้น

**การ์ดสรุปด้านบน:** เอาการ์ด Strategy ออก เหลือ 4 การ์ด

**Strategy ของ bond yield:** US10Y และ US2Y ไม่มี Strategy เหมือน VIX (`NO_STRATEGY` ใน `config.py`) เพราะเป็นอัตราผลตอบแทน ไม่ใช่กราฟราคา

**Cache ของไฟล์ CSS/JS:** ลิงก์ไฟล์ใน `assets/` (ยกเว้น `vendor/`) ทั้ง 3 หน้าต่อท้ายด้วย `?v=<เวอร์ชัน>` ทุกครั้งที่แก้ CSS/JS ให้เปลี่ยนค่านี้ เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่พร้อมกันทั้งชุด ไม่ใช้สคริปต์เก่าปนกับสไตล์ใหม่

## 10. บอกว่าเป็นราคาปิดหรือข้อมูลระหว่างวัน (18 พ.ย. 2026)

ถ้ากดอัปเดตตอนที่บางตลาดยังเปิดอยู่ แท่งล่าสุดของตลาดนั้นจะยังไม่ใช่ราคาปิด

- **ข้อมูลใหม่ต่อสินทรัพย์:** `build_data.py` บันทึก 2 ค่าลงใน `summary.json` และไฟล์ของแต่ละสินทรัพย์
  - `intraday`: true ถ้าดึงข้อมูลก่อนเวลาปิดตลาดของวันที่ของแท่งนั้น
  - `asOf`: เวลาที่ดึงข้อมูล (UTC)
- **เวลาปิดตลาด:** อยู่ที่ `SESSION_CLOSE` ใน `config.py` เป็นเวลาท้องถิ่นของตลาด บวกเผื่อช่วง closing auction ไว้เล็กน้อย
  - ตลาด 24 ชั่วโมง (yield, ทอง, ค่าเงิน, DXY) ตัดแท่งรายวันที่ 17:00 นิวยอร์ก
  - Brent ตัดที่ 23:00 ลอนดอน
- **Tooltip:** ชี้ที่ชื่อสินทรัพย์ใน ticker, ตารางสรุป, Top Movers, Cross-Asset และ bubble บนแผนที่ จะขึ้นข้อความแบบใดแบบหนึ่ง
  - "ราคาปิดตลาด <วันที่>"
  - "ข้อมูลระหว่างวัน <วันที่> ณ HH:MM น. (เวลาไทย) · ตลาดยังไม่ปิด ราคายังเปลี่ยนได้"
- **หน้ากราฟและ Chart Pack:** แสดงข้อความเดียวกันไว้ใต้ชื่อสินทรัพย์
- **ตารางสรุป:** ชี้ที่ส่วนใดของแถวก็ได้ จะขึ้น tooltip เดียวกัน
  - ถ้าเป็นข้อมูลระหว่างวัน คอลัมน์วันที่จะมีป้ายสีส้ม "ระหว่างวัน HH:MM" ให้เห็นได้โดยไม่ต้องชี้
