## 2. การคำนวณฝั่ง Python (`scripts/build_data.py`)

| ตัวชี้วัด | สูตร |
|---|---|
| EMA50 / EMA200 | Exponential moving average ของราคาปิด `span = 50 / 200`, `adjust = False` |
| RSI(14) | Wilder smoothing (`alpha = 1/14`) ของค่าเฉลี่ยกำไรและขาดทุน |
| ATR(14) | Wilder smoothing ของ True Range ใช้กำหนดความกว้างของโซนแนวรับแนวต้าน |
| High 52W | High สูงสุดในช่วง 252 แท่งล่าสุด |
| ระยะห่างจาก High | `ราคาปิด / High52W − 1` |

### แนวโน้ม (Trend)
| สถานะ | เงื่อนไข |
|---|---|
| UPTREND | ราคาปิด > EMA50 > EMA200 |
| DOWNTREND | ราคาปิด < EMA50 < EMA200 |
| SIDEWAYS | กรณีอื่นทั้งหมด |

### Strategy (ตรวจจากบนลงล่าง ใช้ข้อแรกที่ตรง)
| ลำดับ | Strategy | เงื่อนไข |
|---|---|---|
| 1 | ❌ AVOID | ดัชนีหุ้นที่อยู่ quadrant **Lagging** หรือสินทรัพย์อื่นที่เป็น **DOWNTREND** |
| 2 | 🚀 BREAKOUT | ห่างจาก High > −2% |
| 3 | 🟢 BUY DIP | ห่างจาก High −2% ถึง −10% **และ** ราคาปิด > EMA50 |
| 4 | ⚠️ WATCH | ห่างจาก High −2% ถึง −10% **แต่** ราคาปิด ≤ EMA50 |
| 5 | 📉 CORRECTION | ห่างจาก High ต่ำกว่า −10% |

ปรับจาก 5 Action Signals ในเอกสารอ้างอิงเดิม มีคำอธิบายแต่ละสัญญาณ (glossary) อยู่ในหน้า dashboard

### Performance
- ช่วงเวลา: **MTD, 1M, 3M, 6M, 12M**
- MTD = ราคาปิดล่าสุด / ราคาปิดวันสุดท้ายของเดือนก่อน − 1
- nM = ราคาปิดล่าสุด / ราคาปิด ณ วันที่ย้อนหลัง n เดือนตามปฏิทิน (หรือวันทำการก่อนหน้าที่ใกล้ที่สุด) − 1
- ไม่รวม US10Y เพราะ yield ไม่ใช่ราคา

### Market Rotation (heatmap รายเดือน)
- แสดงย้อนหลัง **6 เดือน** เดือนปัจจุบันเป็น MTD
- ผลตอบแทนรายเดือน = ราคาปิดสิ้นเดือน / ราคาปิดสิ้นเดือนก่อน − 1
- แต่ละคอลัมน์เรียงจากดีที่สุดไปแย่ที่สุด แต่ละสินทรัพย์ใช้สีประจำตัว
- ไม่รวม US10Y

### Relative Rotation Graph (RRG)
สูตรประมาณของ JdK RRG (สูตรต้นฉบับไม่เปิดเผย) ใช้แบบ EMA เพราะได้หางที่เรียบกว่า

1. Inner-join ราคาปิดรายวันกับ ACWI (เฉพาะวันที่ซื้อขายตรงกัน) แล้ว resample เป็นรายสัปดาห์ (W-FRI)
2. `RS = 100 × ราคา / ACWI`
3. `RS-Ratio = 100 × EMA10(RS) / EMA30(RS)`
4. `RS-Momentum = 100 × RS-Ratio / EMA10(RS-Ratio)`
5. ตัด 30 สัปดาห์แรกทิ้ง (ช่วง warm-up ของ EMA) แสดงหาง **8 สัปดาห์ล่าสุด**

| Quadrant | RS-Ratio | RS-Momentum | ความหมาย |
|---|---|---|---|
| Leading | ≥ 100 | ≥ 100 | แข็งกว่าตลาดโลก และยังแข็งขึ้น |
| Weakening | ≥ 100 | < 100 | แข็งกว่าตลาดโลก แต่เริ่มแผ่ว |
| Lagging | < 100 | < 100 | อ่อนกว่าตลาดโลก และยังอ่อนลง |
| Improving | < 100 | ≥ 100 | อ่อนกว่าตลาดโลก แต่เริ่มฟื้น |

RRG แสดงเฉพาะดัชนีหุ้น 15 ตัว

## 3. การคำนวณฝั่งเบราว์เซอร์ (`site/assets/analysis.js`)

คำนวณใหม่ทุกครั้งที่เลือกช่วงเวลา (1M / 3M / 6M / 1Y / All) โดยใช้เฉพาะแท่งในช่วงนั้น

### แนวรับแนวต้าน (โซนจาก swing high/low)
1. หน้าต่าง swing `k = clamp(round(n / 40), 2, 10)` โดย n คือจำนวนแท่งในช่วงที่เลือก
2. **Swing high** คือ high ที่สูงสุดในระยะ ±k แท่ง **Swing low** คือ low ที่ต่ำสุดในระยะ ±k แท่ง
3. เรียงราคา pivot แล้ว**รวม pivot ที่ห่างจากค่าเฉลี่ยของกลุ่มไม่เกิน 0.5 × ATR(14)** เป็นโซนเดียว ราคาโซนคือค่าเฉลี่ยของ pivot ในกลุ่ม
4. เก็บเฉพาะโซนที่**แตะอย่างน้อย 2 ครั้ง** (มี pivot ตั้งแต่ 2 จุดขึ้นไป)
5. โซนที่อยู่ใต้ราคาปิดล่าสุดเป็นแนวรับ ที่เหลือเป็นแนวต้าน เก็บ**ไม่เกิน 4 โซนต่อฝั่ง** โดยเลือกโซนที่แตะบ่อยที่สุด
6. ตั้งชื่อ S1… และ R1… ไล่จากใกล้ราคาไปไกล โซนที่แตะบ่อยกว่าเส้นจะหนากว่า

### RSI divergence
- หน้าต่าง swing `k = clamp(round(n / 50), 2, 5)` pivot 2 จุดที่ติดกันต้องห่างกัน **5–60 แท่ง**
- **Bullish:** ราคาทำ low ที่ต่ำลง แต่ RSI ทำ low ที่สูงขึ้น และ RSI ที่ pivot จุดที่สอง < 50
- **Bearish:** ราคาทำ high ที่สูงขึ้น แต่ RSI ทำ high ที่ต่ำลง และ RSI ที่ pivot จุดที่สอง > 50
- แสดงไม่เกิน 3 ครั้งล่าสุดของแต่ละแบบ กล่องสรุปจะแจ้ง divergence เฉพาะครั้งที่จบภายใน 15 แท่งล่าสุด

### RSI Signal
Overbought เมื่อ RSI ≥ 70, Oversold เมื่อ RSI ≤ 30 นอกนั้นเป็น Neutral

## 4. Features

### หน้า Dashboard (`index.html`)
1. **Performance**: กราฟแท่งแนวนอนของ MTD, 1M, 3M, 6M และ 12M แต่ละช่วงใช้สเกลของตัวเอง ชี้เมาส์แล้วเห็นค่า
2. **Market Rotation**: heatmap 6 เดือน ชี้ที่ช่องแล้วสินทรัพย์ตัวเดียวกันจะเด่นขึ้นทุกเดือน
3. **RRG**: ดัชนีหุ้น 15 ตัวพร้อมหาง 8 สัปดาห์ legend เปิด/ปิดได้ทีละตัว และ hover แล้วตัวนั้นเด่นขึ้น
4. **ตารางสรุป**: จัดกลุ่มตามตลาด ไม่จัดอันดับ คอลัมน์: ราคา, %1D, ห่างจาก High 52W, RSI, แนวโน้ม, Strategy, Quadrant และวันที่ข้อมูล คลิกชื่อเพื่อเปิดหน้ากราฟ
5. **Strategy glossary**: เงื่อนไขของแต่ละสัญญาณ วิธีอ่าน และคำอธิบายตัวประกอบ (Trend, Quadrant, RSI)
6. แสดงวันที่ข้อมูลและเวลาอัปเดต ไม่มีแถบเตือนเมื่อข้อมูลเก่า

### หน้า Technical Chart (`chart.html?s=<ID>`)
1. **Lightweight Charts v5.2.1**: แท่งเทียนรายวัน, EMA50 และ EMA200, ช่อง RSI(14) พร้อมเส้น 70/30
2. **ปุ่มช่วงเวลา**: 1M / 3M / 6M / 1Y / All เริ่มต้นที่ 1Y
3. เส้นแนวรับแนวต้านและเส้น divergence (ทั้งบนกราฟราคาและช่อง RSI) คำนวณใหม่ตามช่วงที่เลือก
4. **ช่องติ๊ก**: EMA50, EMA200, RSI + Divergence, แนวรับ/แนวต้าน ติ๊กแล้วยังซูมอยู่ที่เดิม
5. **กล่องสรุป**: แนวโน้มหลัก, ราคาล่าสุด, แนวรับแนวต้านทุกระดับพร้อมจำนวนครั้งที่แตะ, RSI signal + divergence และ Strategy + Quadrant เปลี่ยนตามช่วงที่เลือก
6. **คำบรรยายอัตโนมัติ** (ประโยคแม่แบบภาษาไทยตามกฎ ไม่ใช้ AI)
7. **Export PDF**: เปิดหน้าต่างพิมพ์ของ browser → Save as PDF ได้รายงาน A4 แนวนอนหน้าเดียว กราฟตรงกับที่เห็นบนจอตอนกด รวมช่วงเวลาและช่องติ๊ก

### ทั่วไป
- ป้ายกำกับภาษาไทย ศัพท์เทคนิคภาษาอังกฤษ รองรับมือถือ
